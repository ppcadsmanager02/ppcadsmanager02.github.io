Privacy Policy

Effective date: October 12, 2026

7body Script Control is a private-use integration for managing the operator's Google Apps Script projects. This policy describes the information the integration may access and how it is used.

1. Data accessed

When the Google account owner authorizes the application, it may access Google Apps Script project identifiers, project metadata, filenames and source code through the Google Apps Script API. The integration uses the Google OAuth scope https://www.googleapis.com/auth/script.projects, which permits both reading and updating Apps Script projects. Authentication information, including OAuth refresh tokens, is used to maintain an authorized API connection.

2. Purpose of access

Project information is accessed to perform authorized source-code inventory, diagnostics, backups, integrity checks, change planning and, only through an approved workflow, script updates and verification. The application is not used for advertising profiling, resale of information or unrelated processing.

3. Storage and security

OAuth credentials are intended to be stored as encrypted repository secrets in a private GitHub repository, not in this public website. Authorized workflows can create private diagnostic artifacts, including snapshots of Apps Script code. The current source-snapshot workflow is configured to retain its GitHub Actions artifact for one day; separate platform logs and backups may be subject to GitHub's own retention practices. Public pages and the public repository do not intentionally publish the script source or credentials.

4. Sharing

The integration uses Google services to authenticate and access Google Apps Script projects and GitHub infrastructure to execute authorized automation. These service providers process information as necessary to provide their services under their own terms and policies. We do not sell accessed data or intentionally share it with advertisers or unrelated third parties.

5. Website usage

This website is a static informational site. It does not include an application sign-in, advertising pixels or custom analytics tracking. The hosting provider, GitHub Pages, may collect technical request and diagnostic information under GitHub's privacy statement.

6. Control and deletion

The Google account owner can revoke the application's authorization in their Google Account's third-party connections settings. To request deletion of integration-managed copies or ask a privacy question, contact the operator using the address below. Removing authorization does not necessarily delete artifacts or logs already retained by hosting providers.

8. Changes to this policy
