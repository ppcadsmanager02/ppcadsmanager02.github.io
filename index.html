Private-use integration

7body Script Control

A private-use tool for maintaining and reviewing Google Apps Script projects through the Google Apps Script API and controlled GitHub workflows.

What this application does

  • Reads authorized Google Apps Script project metadata and source files for backup, review and diagnostics.
  • Supports reviewing proposed code changes, version control and integrity checks.
  • May update an explicitly authorized Google Apps Script project only through a separately enabled and approved workflow.

The application is designed for the operator's own Google account and projects. It is not a public SaaS product and does not offer access to third-party Google accounts.

Google account permissions

With the account owner's consent, the application requests the Google Apps Script projects scope (https://www.googleapis.com/auth/script.projects). This scope can access and update Apps Script projects; authorization is used only for authorized project-management tasks.

See our Privacy Policy for details of how source code and authentication information are handled.
